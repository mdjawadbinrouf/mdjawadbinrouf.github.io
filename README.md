# mdjawadbinrouf.github.io

Personal academic website of Md Jawad Bin Rouf, built on the [al-folio](https://github.com/alshedivat/al-folio) Jekyll template and hosted on GitHub Pages.

## Editing

- Bio and research interests: `_pages/about.md`
- Publications: `_bibliography/papers.bib` (add `selected = {true}` to feature a paper on the home page)
- News items: `_news/` (one short Markdown file per item)
- Projects: `_projects/`
- CV page: `_data/cv.yml`, and the PDF at `assets/pdf/Md_Jawad_Bin_Rouf_CV.pdf`
- Photo: replace `assets/img/prof_pic.jpg`
- Colors and fonts: `_sass/_themes.scss`

Every push to `main` rebuilds the site with GitHub Actions and publishes it to the `gh-pages` branch.
